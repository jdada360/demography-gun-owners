# Clean 2017 data

This script cleans the 2017 survey data.

**Input**

-   DemographyGunOwners/data/raw/gunsurvey/2017.rds

**Output**

-   DemographyGunOwners/data/gunsurvey/2017.rds

**Last ran** 

-   02/02/26




## Import data


``` r
source <-
  read_rds(
     here(
      path_od, 
      "data",
      "raw",
      "gunsurvey",
      "2017.rds"
      )
  ) %>% 
  clean_names()
```
